Build a fully functional modern fintech-style mobile application named “ExpenseBuddy” focused on bachelors, roommates, hostel students, and group travelers. The app should combine UPI-based payments, smart expense splitting, group expense management, repayment tracking, and shared wallet management into a single ecosystem.

The application should be production-grade, scalable, visually modern, mobile-first, and built using the latest stable technologies and best practices.

====================================================
APPLICATION CORE IDEA
=====================

The application solves the expense tracking and settlement problems faced by bachelors and group living communities.

Normally:

* one person pays
* others forget repayments
* expenses become messy
* monthly calculations become difficult

This app automates the entire process.

Main concept:
Whenever a user makes a payment, the app instantly asks:
“Do you want to split this expense?”

The app then:

* calculates balances
* tracks repayments
* updates group expenses
* sends notifications automatically

The app should combine:

* UPI app experience
* Splitwise-style group management
* Shared group wallet system
* Expense analytics
